# ROYAL DROP SAFARIS

A booking website for safari adventures and hotel holiday stays.

## Features

- Browse safari and hotel packages.
- Search and filter packages by name, type, and destination.
- View package details and submit booking requests.
- Customer registration and sign-in flow.
- Admin dashboard for package management:
  - Add packages
  - Edit packages
  - Remove packages

## Tech Stack

- React 19 + Vite
- React Router
- Tailwind CSS
- json-server (mock backend)
- Vitest + React Testing Library

## Setup

1. Install dependencies:
   - npm install
2. Start backend:
   - npm run server
3. Start frontend:
   - npm run dev
4. Open the URL shown in terminal (normally http://localhost:5173)

## Testing

- npx vitest run
